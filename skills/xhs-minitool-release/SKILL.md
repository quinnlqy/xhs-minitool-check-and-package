# 小红书小工具检查与打包

根据用户范围检查、修复确认缺陷、制作可追溯离线 ZIP。只检查时沿用既有产物，不默认改代码或重打包。适用于不同项目；不要求特定引擎、玩法或存档键。分享此 skill 不包含上传应用或提交审核授权。

## 确认目标与规则

1. 读项目 AGENTS.md、构建配置和发布记录，找到最近实际交付的入口/ZIP/哈希。保留已有改动、旧包及平台独有修复；不拿默认 dist 或旧构建当最新版本，不从其他平台整目录覆盖。
2. 尝试读取[官方小工具文档](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)，记录日期与结果。成功时当前官方规则优先；失败时说明未核对最新规则，依据用户已有资料和 [平台核对表](references/platform-checks.md) 继续可完成工作。不要称历史配置为当前官方保证。
3. 按产品真实功能选择 [兼容性回归](references/regressions.md)，每项记录适用、执行、结果与未测原因。不要为了清单增加关注、支付、钱包、材质开关等原本没有的功能。

用户提供新版官方 Skill 时先读取其 API 基线，再比较在线公开契约，记录新增能力及参数、版本、配额变化。只调用当前契约明确开放的能力，不将本社区 skill 的历史规则当官方最新版。

## 每次发布的功能完整性

执行 [完整流程与保存检查](references/functional-completeness.md)：

- 空存档首次使用与已有进度分开测试。真实操作关键阶段直到完成、保存和重进；预塞全解锁、改游戏状态或跳阶段只能作专项补充。
- 按钮不仅可见，还要启用、可达、真实命中，tap 后有业务变化。合法前置条件、等待恢复、可滚动到达和真正遮挡/失效分别判断；助手跳过 disabled 按钮不算通过。
- 有原生持久化时从实际操作入口测试健康、拒绝、挂起、假成功、迟到和备份单独挂起。按接口合约确认持久化，超时不等于底层写已取消，重试不得重复扣款/发奖或覆盖更新记录。
- 短屏/横竖屏、滚动、设置/弹窗、返回和重复进入按产品功能覆盖；宿主导航占位须真正拦截点击。WebGL 项目另测实际使用的图形能力和资源释放，普通表单不强加 GPU 测试。
- 补测暂停/弹窗恢复后立即返回再继续的竞态，核对暂停归属、计时与输入恢复；按实际矩形检查响应式缩小后的触摸尺寸。旧 API 缺失从导航前覆盖顶层初始化；用户要求隐藏内容时保留旧档并检查所有入口，正式包检查 URL/环境调试绕过。具体操作见同一完整流程检查表。
- 审核泛化文案只证明有反馈，不指向具体按钮或根因。继续独立排查，修复实际确认问题；不能凭猜测删功能、全机型降画质或保证过审。

## 适配与修复

- 尽量沿用项目构建链并隔离发布目录。仅移植确认修复，记录允许差异及逐文件比较；确认源码构建包含已有热修，避免重建丢修复。
- 加载诊断独立于待加载主 JS/CSS，记录版本、阶段、错误；应用就绪后移除遮罩。不以 CSSOM 可读或后补 load 监听作唯一 ready；旧会话迟到不能复活页面。
- 转译语法和补运行时 API 分开，只补实际使用的缺失能力。非关键版本查询/音效偏好有界等待；权威存档读失败不伪造空档或悄悄换后端。
- 按当前平台要求处理离线资源、脚本格式、入口和相对路径；联网核心无法离线运行时明确阻塞及可行子集，不把压缩 dist 等同适配。
- 不把本项目的工具坐标、配方/价格、账号、业务字段和性能预算带入其他项目。必要诊断保留，发布调试入口与源码映射剔除。

## 打包与最终字节验证

先读 [工具说明](references/tools.md)。脚本只证明其声明范围，不能替代完整业务或原生宿主测试。

1. 用项目发布命令构建。可用 `scripts/package_release.py` 预检和压缩静态目录，输出清单、CRC、文件与 ZIP SHA-256，并解压到全新目录。出现人工复核项必须检查真实代码，不因正则命中就删库或忽略。
2. 测本次 ZIP 解压字节，用子路径、离线 CSP、无外网/缓存、真实 404，避免误测开发服务器或 SPA fallback。运行 `scripts/smoke_release.mjs` 时传 `--package-report` 绑定 ZIP 与解压文件；已有打包器也须提供等价指纹证据。
3. 配置真实 ready 和每次操作后的状态断言；通用 smoke 覆盖健康/CSSOM/crypto 等场景。制作手势、保存/结算、桥接模拟继续用项目专用测试，不能以 body 可见或 smoke 数量替代。
4. 失败则修复、重建、重包、全新解压并重测受影响部分。报告绑定最终哈希；候选失败记录保留，不从多次运行拼出虚假全通过。
5. 交付版本化 ZIP、哈希、大小、清单、规则来源日期、实际覆盖与未测项。官方模拟器、同 SHA 的 Android/iOS 真机和审核结果分别标记；未测就写待验证。没有浏览器工具时说明候选包未验证，不冒充验收完成。

维护本 skill 时读 [资料来源](references/sources.md)，新经验写“触发 → 机制证据 → 修复 → 前后对照 → 未知”。不镜像第三方整份手册或加入私人项目资料。
