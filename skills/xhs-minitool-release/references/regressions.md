# 可观察的检查与回归

按项目实际功能选择场景，记录触发、操作、预期、结果和证据。每次发布还需 [功能完整性](functional-completeness.md)。没有特定功能可说明不适用；没有设备或未运行属于待验证。

| 场景 | 处理与验证 |
| --- | --- |
| 应用已渲染但遮罩截住按钮 | 注入 CSSOM 不可读/延迟资源；独立加载诊断，实际就绪后移除拦截层；真实点击进入下一视图 |
| 资源缺失/语法失败/迟到加载 | 分别 abort、替换非法脚本、延迟返回；错误阶段可解释，重试/返回可操作；旧请求不能复活已退出页面 |
| 旧 API 缺失 | 移除项目实际使用的 globalThis、数组/DOM/Canvas 方法、dialog 等；初始化前局部兼容；不能只转译语法 |
| crypto/随机 ID 不可用 | 按用途作合理回退，访问抛错和方法缺失分开测；有效存档不因业务初始化异常被清空。安全用途不能套普通游戏 ID 回退 |
| 空档/坏档/读取拒绝混淆 | 缺 key、空白、截断、备份、有效旧档、访问拒绝分开；保留损坏原文，可恢复/重试，不自动写零 |
| 原生缺 key 报 JSON EOF | 按 SDK 合约和权威 key 查询判断不存在；未知/存在不能一律吞错误 |
| 元数据/音效查询挂起 | 非关键任务有界，能力选择后本次存储后端固定；原生支持已确认但读取失败不能偷偷换空档 |
| 主写失败、假成功、备份挂起 | 按 [持久化矩阵](functional-completeness.md) 测实际操作；保存确认、超时恢复、未完成写保护、备份串行与幂等 |
| 角落按钮与宿主导航重叠 | 原生占位真正接收点击；查矩形/命中并真实 tap；覆盖首页、设置、弹窗和结果页 |
| 短屏/旋转/安全区迟到 | 按可视区域布局，安全区变化不一定附带 resize；滚动容器可缩小且可手指滚动；不要重复扣高度 |
| 跨画布与 UI 拖动 | 工具/材料交接、坐标与 pointer capture 分开；UI 预览不抢点击，不留残影；测放置/取消/撤销和库存 |
| 手势抢占/页面滚不了 | 局部 touch-action/事件仲裁；工具接触、空白视角、多指、真实图片/文字滚动和按钮轻微漂移分别测 |
| ResizeObserver 通知或反馈循环 | 区分已知 loop 通知和真实错误；若 canvas 固有尺寸反推布局，修正尺寸责任。不能全吞 window.onerror 或禁用观察器作修复 |
| 材质局部发黑 | 健康原材质保留；在真实渲染链加可信对照才能自动判定；未知保留可解释状态，兼容/手动选择按产品需要，不能按手机品牌猜测 |
| WebGL 不支持/context loss | 明确可操作的轻量失败、重试/返回；资源预算与降级有依据，不发明未授权替代玩法 |
| 退出后节点或旧回调残留 | 作用域/会话标识管理 observer、监听、RAF、音频、渲染器、脱离容器的预览；测退出、取消、重试、重复进入和迟到回调 |
| 源码通过、上传包不是那份 | 显式定位最终 ZIP，校验指纹及逐文件差异；无缓存/离线/子路径/真实 404，改包后刷新对应证据 |
| 泛化审核文案 | 确认运行版本和原文，继续本地排查；没有具体步骤就保持审核根因未知，不把某个本地修复称为必过审核 |

不同平台独立保留入口、资源、SDK、存储和规则；不要共享整包覆盖。测试数量不是功能覆盖的替代，也不把受控故障称为真实宿主或手机复现。
